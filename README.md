# 澄序 s-PM

汪诺的个人项目、联系人与日程管理系统。

## 当前功能

- 个人登录与数据看板
- 项目、联系人和全局搜索
- 项目、人员、日程与附件软删除，可从回收站恢复
- 按项目或联系人筛选日程
- 日、周、月、年日历视图
- 日程文档与图片附件交互

## 本地开发

需要 Node.js 22.13 或更高版本。

```bash
pnpm install
pnpm dev
pnpm build
```

演示账号和密码均为 `demo`。当前为交互原型，正式部署阶段将接入独立数据库、服务端鉴权和腾讯 COS。

## 部署原则

本项目将使用独立项目目录、运行用户、端口、进程、数据库与环境变量，通过单独的域名反向代理对外提供服务，避免影响服务器上其他项目。

- 项目目录：`/home/ubuntu/s-pm`
- 数据目录：`/home/ubuntu/s-pm-data`
- 本机端口：`127.0.0.1:3108`
- PM2 进程：`s-pm-web`
- SQLite 数据库：`/home/ubuntu/s-pm-data/s-pm.sqlite`
