# 澄序 s-PM

汪诺的个人项目、联系人与日程管理系统。

## 当前功能

- 个人登录与数据看板
- 两级项目树，主项目可统一查看子项目日程与进度
- 项目概览、参与人员关联、待办与里程碑
- 项目和联系人标签筛选，以及项目、联系人、日程、待办全局搜索
- 项目、人员、日程与附件软删除，可从回收站恢复
- 按项目或联系人筛选日程
- 日、周、月、年日历视图
- 周/月视图拖动日程改期，新建时自动带入当前项目或联系人
- 日程文档与图片附件交互
- 创建、修改、删除、恢复和改期操作记录

## 本地开发

需要 Node.js 22.13 或更高版本。

```bash
pnpm install
pnpm dev
pnpm build
```

生产环境使用独立 SQLite 数据库、服务端鉴权与腾讯 COS；账号信息不写入仓库。

## 部署原则

本项目将使用独立项目目录、运行用户、端口、进程、数据库与环境变量，通过单独的域名反向代理对外提供服务，避免影响服务器上其他项目。

- 项目目录：`/home/ubuntu/s-pm`
- 数据目录：`/home/ubuntu/s-pm-data`
- 本机端口：`127.0.0.1:3108`
- PM2 进程：`s-pm-web`
- SQLite 数据库：`/home/ubuntu/s-pm-data/s-pm.sqlite`
